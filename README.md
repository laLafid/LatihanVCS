# Cara Menggunakan Git

## Persiapan 

1. [Git](https://git-scm.com/)
2. [Github](https://github.com/)

## Prep Time

Sebelum menggunakan [Git](https://git-scm.com/), pastikan bahwa [Git sudah ada](#menggunakan-git) di sistem komputer mu.

Jika [Git](https://git-scm.com/) belum terinstall di komputer mu, ikuti [petunjuk](#instalasi-git) ini:

## Instalasi Git

1. [Download Git](https://git-scm.com/downloads)
    Sesuaikan dengan komputer kalian

2. Jalankan installer Git
    Setelah menyelesaikan download, buka file installer git 

![alt text](<gambar/install git.png>)

3. Proses instalasi
    Klik "Next" hingga instalasi selesai.

4. Cek instalasi
    Buka cmd/ps atau git bash untuk memastikan git sudah terinstal dengan benar.

![alt text](gambar/cek.png)
